How it works

Press the button and it picks one game from the UK console Game Pass list. That's tonight's game. No re-rolls.

Honest random. Each spin gets a code from your browser's crypto random number generator. The code decides everything: the reel, the jokes, the fake-outs and the final game, drawn evenly from every eligible game. The fake-outs are theatre; the last stop is the real pick.

Check it yourself. Open ?seed=CODE and the identical spin plays again, from the same day's catalogue.

Games already played are left out. The list refreshes from Microsoft's public catalogue once a day.
